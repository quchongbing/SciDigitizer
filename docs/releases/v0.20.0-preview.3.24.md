# SciDigitizer 0.20.0 Preview 3 Patch 24

Recalibrate saved data without retracing, with improved scatter extraction.
支持重新标定已存数据，无需重新提取；同时改进散点识别。

## Changes / 更新

- Apply corrected X/Y calibration to one saved curve or all saved curves. Pixel points are preserved; undo and redo are supported. Other curves keep their independent calibration.
  可将修正后的 X/Y 标定应用到指定曲线或全部已存曲线，保留原图上的点，支持撤销和重做；未选曲线保留独立标定。
- Select **Scatter / marker centers**, then click a clear point to extract same-colour markers. Optional guides preserve multiple Y values at the same X unless strict guidance is enabled.
  选择“散点 / marker 中心”后，点击一个清晰点即可提取同色标记。默认保留同一 X 对应的多个 Y；引导点不会自动压缩散点云。
- Automatic curve-type detection runs again when selecting a new target. Clear thin lines skip unnecessary marker analysis.
  更换目标时重新判断曲线类型；清晰细线减少不必要的散点分析。
- Reject confirmed plot-frame pixels while retaining targets explicitly selected along the frame.
  排除已确认的坐标边框像素，同时保留明确选在边框附近的目标。

## Downloads / 下载

Choose the package for your system from **Assets** below. Windows, Linux and macOS packages are provided, including a Debian/Ubuntu x64 installer. Check downloaded files against `SHA256SUMS.txt`.

在下方 **Assets** 中选择对应系统的安装包，提供 Windows、Linux 和 macOS 版本，以及 Debian/Ubuntu x64 安装包。文件校验值见 `SHA256SUMS.txt`。

## Verification / 验证

265 automated tests; 60 scatter cases covering 6,135 separate symbols; 2,100 Pen cases; 43 accuracy checks; 20 bundled-image cases; and HTTP/Worker and offline browser workflows, including recalibration, export and project restore.

265 项自动测试；60 组散点案例，覆盖 6,135 个分离标记；2,100 组 Pen 测试；43 项精度检查；20 组内置图片案例；以及包含重新标定、导出和项目恢复的网页及离线浏览器流程。

Dense overlapping symbols remain a limitation. Desktop packages are unsigned; native Windows/macOS launches have not yet been verified.
密集粘连的散点仍有限制。桌面安装包尚未签名，Windows/macOS 原生启动尚未完成验证。
