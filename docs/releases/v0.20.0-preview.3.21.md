# SciDigitizer 0.20.0 Preview 3 Patch 21

This preview publishes the current development snapshot as a new, immutable
release. Older tags and downloads are not replaced.

本预览版发布当前开发快照，使用新的版本标签；不覆盖旧版本及其安装包。

## Changes / 主要改进

- Preserves the one-click workflow for ordinary curves, including the steep
  green sample. Pen and guide points remain optional assistance.
  保持普通曲线的一键提取流程，包括示例图中的陡峭绿色曲线；Pen 和引导点仍是可选辅助。
- Strengthens local Pen constraints: the painted section cannot be bypassed
  sideways onto another curve; tracing can extend beyond its two dashed end
  boundaries. Horizontal, vertical and 2D tracing share the same scope.
  加强局部 Pen 约束：不能从涂画区段侧面绕到其它曲线，允许从两端虚线边界接续；
  横向、纵向及二维追踪遵守相同范围。
- Improves near-vertical and mixed-direction paths, guide preservation,
  neutral grey/black colour selection, curve-centre refinement and sampling.
  改进近垂直及横竖混合路径、引导点保护、灰色/黑色取色、线宽中心校正及采样。
- Adds multi-reference manual calibration checks, independent calibration
  per saved curve, guided 2D paths, and conservative occlusion/patterned-gap
  reconnection. Inferred sections remain explicitly marked for review.
  支持多参考点人工标定检查、每条已存曲线独立标定、引导二维路径及保守的遮挡/虚线
  重连；推断部分仍明确标记，需人工复核。坐标轴不会自动标定。
- Starts a fresh image session by default; saved browser drafts are restored
  only by an explicit user action. Invalid restored traces retain their
  coordinates but must be retraced before editing or export.
  默认从新会话开始；浏览器草稿需主动恢复。恢复后不符合约束的旧追踪仍保留坐标，
  但重新追踪前不能编辑或导出。
- Adds regression coverage for sampling/export Pen constraints and isolated
  HTTP/Worker and offline `file://` browser workflows.
  增加采样/导出 Pen 约束检查，以及隔离运行的 HTTP/Worker 和离线浏览器回归测试。

available without installation. Images and computation stay on your device.

[在线版](https://quchongbing.github.io/SciDigitizer/)仍可免安装使用，图片和计算保留在本机。

## Validation and limitations / 验证与限制

Release gates include syntax/bundle checks, **174 automated tests**, **43
accuracy regression metrics**, **11 bundled-example cases**, and HTTP/Worker
plus offline browser workflow tests. Package verification checks version,
file inventory, size and SHA-256 values before upload.

发布检查包含语法及离线 bundle 一致性、**174 项自动测试**、**43 项精度回归指标**、
**11 个内置示例案例**和 HTTP/Worker、离线浏览器流程。上传前检查安装包版本、
文件清单、体积及 SHA-256 值。

These are unsigned preview packages, not a claim of native validation on every
operating system. Windows SmartScreen and macOS Gatekeeper may show warnings.
Linux requires GTK 3 and WebKitGTK 4.1 or 4.0; the small downloads reuse the
system WebView rather than bundling a browser.

这些仍是未签名预览包，不能把自动测试或跨平台打包等同于每个系统的原生验收。
Windows/macOS 可能显示安全提示。Linux 需要 GTK 3 和 WebKitGTK 4.1 或 4.0；
小体积依赖复用系统 WebView，而非内置浏览器。

For a mixed-direction curve crossing other same-colour lines, paint the full
route and add at least three guides around the crossing and turn. If Auto
cannot resolve it, try explicit 2D tracing. Completely hidden sections and
indistinguishable branches cannot be uniquely recovered; review the result.
See [Pen and vertical tracing](https://github.com/quchongbing/SciDigitizer/blob/v0.20.0-preview.3.21/docs/PEN_AND_VERTICAL_TRACING.md).

横竖混合曲线若穿过其它同色线，请涂画完整路径，并在交叉与转弯前后添加至少三个
引导点；自动模式无法判断时可尝试显式二维追踪。完全遮挡或无法区分的分支不能
唯一恢复，结果需复核。详见 [Pen 与垂直曲线说明](https://github.com/quchongbing/SciDigitizer/blob/v0.20.0-preview.3.21/docs/PEN_AND_VERTICAL_TRACING.md)。
