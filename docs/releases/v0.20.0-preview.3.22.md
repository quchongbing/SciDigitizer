# SciDigitizer 0.20.0 Preview 3 Patch 22

Fixes Pen tracing, marker editing and draft recovery.
修复 Pen 追踪、标记点编辑和草稿恢复。

## Changes / 修复内容

- Pen can be painted before the first target pick. Local tracing connects through rounded brush ends while staying within the selected section.
  支持先画 Pen 再选择目标；局部追踪可从圆头笔迹接续，并遵守所选区段的约束。
- Improves full-path selection for inclined and near-vertical dashed curves.
  改进倾斜、近垂直虚线的完整路径选择，减少提取中途截断。
- Erased gaps remain blocked during sampling, draft restoration and export.
  采样、恢复草稿和导出时均检查擦除缺口，防止越界连接。
- Reducing marker count retains guide markers and keeps CSV/TXT export working.
  减少标记点数量时保留引导标记，修复因此导致的 CSV/TXT 导出失败。
- Rechecks restored drafts and saved curves. Invalid results keep their coordinates and require retracing.
  恢复草稿时重新检查当前及已存曲线；不符合约束的结果保留坐标，需重新追踪。
