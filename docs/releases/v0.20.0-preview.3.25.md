# SciDigitizer 0.20.0 Preview 3 Patch 25

Release candidate — not published yet.
待验证版本，尚未发布。

## Changes / 更新

- Pen defaults to **Local assistance** for new curves. Paint only the section that needs correction; full-route restriction remains available. A failed trace keeps the previous points for reference and offers a local-mode retry when appropriate.
  新曲线的 Pen 默认使用“局部辅助”，只需涂需要修正的区段，仍可选择完整路径约束。追踪失败时保留旧点供对照，适用时可直接切换局部辅助重试。
- Painted solid-line tails can continue through an occlusion. These points are marked as estimates, not recovered measurements; Pen boundaries and eraser cuts still apply.
  实线尾部被遮挡时，可沿涂画路径延续。补出的点明确标为估计，并非恢复的原始数据；仍受 Pen 边界和擦除区域约束。
- Desktop builds now include the missing native client. macOS apps are signed after resource embedding, and their minimum OS version is read from the executable. Windows instructions cover the WebView2 Runtime dependency.
  桌面版补齐缺失的原生客户端。macOS 应用在资源嵌入后签名，最低系统版本与可执行文件保持一致。Windows 安装说明补充 WebView2 Runtime 依赖。
- Windows and both Mac architectures are built and smoke-tested on their native systems before release. Existing release files are never overwritten.
  发布前在 Windows、Intel Mac 和 Apple Silicon Mac 上分别构建并执行启动检查，不覆盖旧版发布文件。

## Verification / 验证

Local checks passed: 289 automated tests, scatter regressions, Pen stress tests, accuracy checks and bundled-image regressions. Cross-platform CI results are pending.

本地已通过 289 项自动测试，以及散点、Pen 压力、精度和内置图片回归。跨平台 CI 结果待确认。

Windows packages have no publisher signature. macOS ad-hoc signatures do not provide Developer ID verification or Apple notarization; first-launch security prompts may remain. Native smoke tests do not cover download quarantine or every OS configuration.

Windows 安装包没有发布者签名。macOS 临时签名不等于 Developer ID 签名或 Apple 公证，首次启动仍可能出现安全提示。原生启动测试不覆盖下载隔离及所有系统配置。

请参考[安装指南](../installation.md)。本候选版本尚未发布新的安装包。
