# SciDigitizer 0.20.0 Preview 3 Patch 23

Improves same-colour guidance and fixes false Pen errors on steep curves.
增强同色分支引导，修复陡峭曲线误报 Pen 追踪失败的问题。

## Changes / 更新

- Solid-line guidance strengthens locally where same-colour branches compete. Add guides before and after the ambiguous section; the manual constraint setting stays unchanged.
  实线遇到同色竞争时自动局部增强引导。在歧义区段前后加引导点即可，不会自动勾选强约束。
- Steep ordinary curves no longer require a 2D route solely because of guide geometry. Pen-specific failure messages appear only when a Pen is active.
  普通曲线不会仅因陡峭段的引导点排列而被强制改用二维路径；没有使用 Pen 时，不再误提示补涂走廊。
- Failed retracing retains the last result as grey dashed circles for reference. Editing and export remain paused until the trace succeeds or the change is undone.
  重新追踪失败时，上次结果以灰色虚线圆点保留供对照；成功重追踪或撤销修改前，暂停编辑和导出。
- Guides keep their coordinates. Inferred points, sampling and restored projects retain Pen constraints and provenance.
  引导点坐标保持不变；推断点、采样和项目恢复继续遵守 Pen 约束并保留来源信息。

## Verification and limits / 验证与限制

The regression suite covers 194 unit tests, 2,100 Pen cases, 43 accuracy checks,
20 bundled-image cases, and HTTP/Worker and offline browser workflows. The reported
XRD curve was also checked locally in both browser modes without a Pen.

回归检查包括 194 项单元测试、2,100 组 Pen 测试、43 项精度检查、20 组内置图片案例，
以及 HTTP/Worker 和离线浏览器流程。反馈中的 XRD 曲线也在本地两种浏览器模式下
完成了不使用 Pen 的验证。

Hidden details remain estimates, not measured pixels. These preview packages
are unsigned and reuse the system WebView. Native Windows/macOS launches have
not yet been verified.

被完全遮挡的细节仍是估计值，并非像素观测。这些预览安装包尚未签名，使用系统
WebView；Windows/macOS 原生启动尚未完成验证。
