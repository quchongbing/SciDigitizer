## Latest refinements / 本次小修改

- Reorganizes the Trace curve panel around one prominent target-selection action. Optional curve type, guidance, Pen, sampling, and advanced controls stay collapsed until needed.

  重新组织“追踪曲线”面板，突出一次点击选择目标；曲线类型、引导、Pen、采样和高级设置按需展开。
- Adds a confirmed **Start fresh** action that removes the current image's autosaved browser draft without affecting downloaded projects, CSV/TXT files, or source images.

  新增带确认提示的“重新开始”，只清除当前图片的浏览器自动保存草稿，不影响已下载项目、CSV/TXT 或原图片。
- Supports opening a complete source copy directly through `file://.../index.html`; the built-in sample and pixel analysis now work without a terminal or local server.

  支持通过 `file://.../index.html` 直接打开完整源码目录，示例图和像素分析无需终端或本地服务器即可工作。
- Removes the decorative “Step 1” badge and keeps the primary instruction visually simple.

  删除容易被误认为功能图标的“Step 1”圆形徽章，保留简洁的主操作说明。
