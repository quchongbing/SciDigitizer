# SciDigitizer 0.20.0 Preview 3 Patch 19

This reliability patch hardens guided two-dimensional extraction, editable
state recovery, project import, and release verification without changing the
ordinary one-click workflow.

本可靠性补丁加强了二维引导提取、可编辑状态恢复、项目导入和发布校验，同时不改变普通曲线的一键提取流程。

## Changes / 主要变化

- Keeps inferred occlusion and patterned-gap points independent of pixels that
  users explicitly masked, and preserves their provenance after resampling.
- Deduplicates overlapping masks, preserves coincident or subpixel-near guide
  points, and rejects unreconnected dash fragments instead of reporting them as
  complete curves. Short open 2D fragments are also scored by their real arc
  length instead of receiving automatic full coverage.
- Uses strict patterned guidance only when repeated same-colour competition is
  actually detected, so ordinary curved dashed lines remain flexible.
- Invalidates stale background work during Undo/Redo, restores trace direction
  and automatic line-style metadata, and keeps a locally imported image when
  starting fresh.
- Validates project geometry and identifiers before applying it, blocks remote
  sample paths, and makes repeat selection of the same project file reliable.
- Runs real-image smoke checks in CI and adds category-level accuracy gates for
  guided patterned curves.
- Makes the development server local-only by default and adds immutable release
  package/version/checksum verification.

- 遮挡和虚线缺口推断点不再读取用户已明确屏蔽区域中的像素，重采样后仍保留推断来源。
- 重叠遮挡框会去重；重合或亚像素相邻的引导点都会保留；无法可靠重连的单个虚线片段不会再被误报为完整曲线。
- 只有实际检测到持续的同色分支竞争时才启用严格虚线引导，普通弯曲虚线仍保持自然追踪。
- 撤销/重做会使旧后台任务失效，并恢复追踪方向和自动线型信息；“重新开始”会保留当前本地图片。
- 项目几何和标识符在应用前会校验，远程示例路径会被拒绝，同一项目文件可再次选择。
- CI 增加真实图片测试和虚线多引导类别的绝对精度门槛。
- 开发服务器默认只监听本机，并增加不可变版本、包文件和 SHA-256 校验。

Known limitation / 已知限制: a patterned curve beside an exact same-colour
distractor can still require several guide points or a Pen corridor. This patch
prevents silent overconfidence; it does not claim that every such one-click case
is solved.

当虚线旁存在完全同色的干扰曲线时，仍可能需要多个引导点或 Pen 走廊。本补丁避免静默给出过度自信的错误结果，但不宣称已经解决所有此类一键场景。
