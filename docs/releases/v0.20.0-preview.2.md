# SciDigitizer v0.20.0-preview.2

This preview fixes canvas and point flicker reported in the first desktop release. The browser edition is also updated at <https://quchongbing.github.io/SciDigitizer/> and requires no installation.

本预览版修复了首个桌面版本中画布和数据点随鼠标移动闪烁的问题。无需安装也可直接使用已更新的[在线版](https://quchongbing.github.io/SciDigitizer/)。

## Changes / 主要变化

- Separates the stable source image from the transparent interactive overlay, so pointer movement no longer clears and redraws the full raster. / 将稳定原图与透明交互标记层分离，鼠标移动不再清空并重画整幅图像。
- Coalesces rapid pointer events into at most one overlay update per display frame. / 将连续鼠标事件合并为每个显示帧最多一次标记层更新。
- Keeps Overlay PNG export complete by compositing the source image and annotations during export. / 导出 Overlay PNG 时重新合成原图和标记，确保结果完整。
- Adds a concise bilingual installation guide for Windows, Linux, and macOS. / 增加简洁的 Windows、Linux 与 macOS 中英文安装教程。

## Downloads / 下载选择

- Windows 10/11 x64: `SciDigitizer-0.20.0-preview.2-windows-x64.zip`
- Linux x64: `SciDigitizer-0.20.0-preview.2-linux-x64.deb` for Debian/Ubuntu-family systems, or the portable `SciDigitizer-0.20.0-preview.2-linux-x64.zip`
- Linux arm64: `SciDigitizer-0.20.0-preview.2-linux-arm64.zip`
- macOS Intel: `SciDigitizer-0.20.0-preview.2-macos-x64.zip`
- macOS Apple Silicon: `SciDigitizer-0.20.0-preview.2-macos-arm64.zip`

All packages remain approximately 1–1.3 MiB. Compare downloaded files with `SHA256SUMS.txt` when integrity matters.

所有安装包仍约为 1–1.3 MiB。如需确认文件完整性，请使用 `SHA256SUMS.txt` 校验。

## Upgrade / 升级

Ubuntu and Debian users can install the new `.deb` over preview 1. Its internal version is `0.20.0-0preview2`, which is newer than the legacy preview 1 package (`0.20.0`) and older than the planned final package (`0.20.0-1`). Portable Windows, Linux, and macOS users should replace the old extracted application with the new one.

Ubuntu 和 Debian 用户可直接在 preview 1 上安装新的 `.deb`；其内部版本为 `0.20.0-0preview2`，高于旧 preview 1 包的 `0.20.0`，同时低于计划中的正式包 `0.20.0-1`。Windows、Linux 和 macOS 便携版用户请用新解压的应用替换旧版本。

## Preview notice / 预览版说明

These packages are not yet code-signed or notarized. Windows SmartScreen and macOS Gatekeeper may display a warning. Download only from this official GitHub release. On macOS, Control-click the app and choose **Open** for the first launch. Linux requires GTK 3 and WebKitGTK 4.1 or 4.0.

这些安装包尚未进行代码签名或 Apple 公证，因此 Windows SmartScreen 或 macOS Gatekeeper 可能显示安全提示。请仅从本 GitHub 官方发布页下载。macOS 首次启动时可按住 Control 点击应用并选择**打开**。Linux 需要 GTK 3，以及 WebKitGTK 4.1 或 4.0。

This preview has no automatic updater. Existing browser and preview 1 project files remain compatible, but important extracted data should still be exported separately as CSV or TXT.

本预览版暂不提供自动更新。浏览器版和 preview 1 的项目文件仍然兼容，但重要数据仍建议另外导出为 CSV 或 TXT 保存。
