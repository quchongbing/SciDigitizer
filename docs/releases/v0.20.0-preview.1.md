# SciDigitizer v0.20.0-preview.1

First public desktop preview of SciDigitizer 0.20.0. The browser edition remains available at <https://quchongbing.github.io/SciDigitizer/> and requires no installation.

SciDigitizer 0.20.0 的首个公开桌面预览版。无需安装也可直接使用[在线版](https://quchongbing.github.io/SciDigitizer/)。

## Highlights / 主要功能

- Local-only PNG, JPEG, and WebP processing; imported images are not uploaded. / 图片仅在本机处理，不会上传。
- Manual Linear, Log10, and Piecewise calibration with independent calibration per saved curve. / 支持人工线性、对数、分段标定及每条曲线独立标定。
- Guided tracing, subpixel stroke-center refinement, adaptive sampling, multi-curve avoidance, and occlusion estimation. / 支持引导追踪、亚像素线宽居中、自适应采样、多曲线避让和遮挡估计。
- CSV, TXT, project JSON, and overlay PNG export. / 支持 CSV、TXT、项目 JSON 和叠加图导出。

- Windows 10/11 x64: `SciDigitizer-0.20.0-windows-x64.zip`

- Linux arm64: `SciDigitizer-0.20.0-linux-arm64.zip`
- macOS Intel: `SciDigitizer-0.20.0-macos-x64.zip`
- macOS Apple Silicon: `SciDigitizer-0.20.0-macos-arm64.zip`

All packages are approximately 1–1.3 MiB. Compare downloaded files with `SHA256SUMS.txt` when integrity matters.

所有安装包约为 1–1.3 MiB。如需确认文件完整性，请使用 `SHA256SUMS.txt` 校验。

## Preview notice / 预览版说明

These packages are not yet code-signed or notarized. Windows SmartScreen and macOS Gatekeeper may display a warning. Download only from this official GitHub release. On macOS, Control-click the app and choose **Open** for the first launch. Linux requires GTK 3 and WebKitGTK 4.1 or 4.0.

这些安装包尚未进行代码签名或 Apple 公证，因此 Windows SmartScreen 或 macOS Gatekeeper 可能显示安全提示。请仅从本 GitHub 官方发布页下载。macOS 首次启动时可按住 Control 点击应用并选择**打开**。Linux 需要 GTK 3，以及 WebKitGTK 4.1 或 4.0。

This preview has no automatic updater. Existing browser projects remain compatible, but important extracted data should still be exported separately as CSV or TXT.

本预览版暂不提供自动更新。浏览器版项目文件仍然兼容，但重要数据仍建议另外导出为 CSV 或 TXT 保存。
