# Contributing to SciDigitizer

Thank you for helping improve SciDigitizer. Bug reports, reproducible scientific-plot cases, documentation improvements, and focused pull requests are welcome.

Please run the relevant checks before submitting code:

```bash
npm run check
npm test
npm run smoke:real
```

By submitting a contribution, you confirm that you have the right to provide it and agree that it is licensed under the repository's MIT License. Do not add publication figures, screenshots, datasets, fonts, or other third-party material unless their source and redistribution license are documented and compatible with the project.
